# Data

The dataset is **not** stored in this repository. Download it from the source:

**Online Retail II** – UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/502/online+retail+ii
DOI: [10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D) · Licence: CC BY 4.0

Unzip `online_retail_II.xlsx` into the project's top-level folder (next to `segmentation_pipeline.py`).

| Property | Value |
|---|---|
| Rows | 1,067,371 transaction lines |
| Period | 01 Dec 2009 – 09 Dec 2011 |
| Attributes | Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, Country |
| Customers after cleaning | 5,861 |

Citation: Chen, D. (2019) *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
